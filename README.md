# ro-iteminfo-llm-translator
⚒️ Um tradutor offline e automatizado de arquivos ItemInfo.lua e textos de Ragnarok Online. Utiliza LLMs locais (GGUF via llama-cpp) com preservação estrita de tags de cores, quebras de linha e placeholders através de expressões regulares nativas. Possui interface gráfica em CustomTkinter e suporte a aceleração por hardware (Vulkan/CUDA).
